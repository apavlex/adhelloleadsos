AdHello Leads

Connect the extension to your AdHello workspace.

Import a lead list

Upload a CSV or Excel file and file every row into a folder (created automatically if it does not exist).

Import modes

  • Bulk scrape — Google Maps search results only (extension → Bulk scrape tab).
  • Save lead — one at a time on Google Maps, Yelp, directories, social, and listing sites.
  • Import CSV — any export (Google, Yelp, Outscraper, SmartScraper, spreadsheets).

Setup

  1. Copy API_INGEST_KEY from your AdHello server environment.
  2. Use your production URL or http://localhost:3000 for local dev.
  3. Set workspace ID if you use multi-workspace (defaults to default).
  4. Visit a supported profile or listing — social, Google Maps, Yelp, Groupon, Craigslist, Nextdoor, Houzz, and more.
